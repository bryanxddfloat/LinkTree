Explorando o CSS Interno

O CSS é utilizado para alterar a aparência dos elementos criados com HTML.

Seletores de tag

Podemos utilizar o nome de uma tag como seletor. Por exemplo, podemos alterar a aparência de todos os parágrafos da página.

Exemplo

Neste parágrafo temos um texto emnegrito, um texto em itálico e uma palavra destacada.

Seletores descendentes

Também podemos selecionar elementos que estão dentro de outros elementos. Neste caso, podemos aplicar estilos específicos aos elementos b, i e mark quando eles estiverem dentro de um parágrafo.

  • Este negrito não recebe a formatação
  • E nem este itálico

Outro exemplo

Podemos deixar uma palavra em negrito, outra em itálico e também destacar uma informação importante.
