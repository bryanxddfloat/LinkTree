Clique nos tópicos abaixo para descobrir algumas curiosidades sobre tecnologia.

Como surgiu a Internet?

A Internet surgiu a parir de pesquisas e projetos de comunicação entre computadores. Um dos projetos mais importantes foi a ARPANET na década de 1960.

O que significa HTML?

HTML significa Linguagem de Marcação de Hipertexto e é usado para estruturar conteúdo.

É a linguagem mais importante da web.

Para que serve CSS?

CSS serve para estilizar e deixar as páginas da web mais bonitas e organizadas. Ele define cores, fontes, tamanhos, espaçamentos, posições e layouts dos elementos HTML.

Para que serve JavaScript

JavaScript serve para dar interatividade e comportamento às páginas da web. Ele permite criar ações como botões funcionais, animações, formulários, menus e atualizações de conteúdo sem recarregar a página.

Como publicar um site?
  1. Criar os arquivos do site, como HTML, CSS e JavaScript.
  2. Escolher uma plataforma de hospedagem, como GitHub Pages, Netlify ou Vercel.
  3. Enviar os arquivos para a plataforma.
  4. A plataforma gera um link público para acessar seu site.

Para quem está começando, GitHub Pages é uma opção simples e gratuita.
