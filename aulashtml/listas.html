Trabalhando com listas

Listas são estruturas para representação de conteúdo na forma de uma relação de itens.

Lista não-ordenada

Relação de itens em que a sequencia não importa.

Exemplo: Materiais escolares

  • Lápis
  • Caderno
  • Borracha
  • Caneta

Lista ordenada

Relação de itens em que a sequencia importa.

Exemplo: passo a passo para estudar

  1. Escolher o assunto/conteúdo
  2. Ler o material
  3. Fazer exercícios
  4. Revisar

Lista dentro de lista

Exemplo: disciplinas escolares

  • Matemática
    • Álgebra
    • Geometria
    • Porcentagem
  • Português
    • Gramática
    • Literatura
    • Redação
  • Programação
    • Front-End
      • HTML5
      • CSS
    • Back-End
      • PHP
      • SQL
      • Node.js
