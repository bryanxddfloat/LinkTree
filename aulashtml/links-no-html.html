Trabalhando com links (ou hiperlinks)

Os links permitem conectar páginas, acessar outros sites e direcionar o usuário para diferentes recursos.

Para criar links utilizamos a taga e o atributo href.

Exemplo 1: link para outro site

Visite o site da Mozilla para informaçoes sobre Front-End:

MDN Web Docs

Outro site importante é o W3C

Visite o site do Senac

Exemplo 2: abrindo o link em outra aba/guia

Para forçar a abertura do link em outra aba/guia do navegador, usamos o atributo target com o valor _blank.
